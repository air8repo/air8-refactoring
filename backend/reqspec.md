# 再保理系统需求规格说明书

> ⚠️ 本文档为历史参考，已被 [docs/system/requirements.md](../docs/system/requirements.md) 取代，不再维护。

## 1. 引言

### 1.1 文档目的

本文档旨在详细描述再保理系统的功能需求、非功能需求、业务流程和数据规范，为系统设计、开发和测试提供明确的指导。

### 1.2 术语定义

| 术语 | 定义 |
|------|------|
| 再保理 | 银行或金融机构从保理商手中买断卖方企业的应收账款，同时承担与该应收账款相关的信用风险 |
| 融资订单 | 记录企业融资申请的单据，包含发票信息、融资金额、到期日等 |
| 还款订单 | 记录企业还款情况的单据，包含还款金额、还款日期、还款状态等 |
| 银行对账单 | 银行提供的记录企业账户收支情况的单据 |
| 融资概览 | 聚合融资订单、还款记录和银行对账单的综合视图 |
| 批次管理 | 对融资单进行分组管理的功能，便于批量处理 |
| Onboarding配置 | 企业加入系统时的基础配置信息 |

## 2. 功能需求

### 2.1 用户认证与权限管理

#### 2.1.1 用户登录

**需求描述**：系统应支持用户登录功能

**输入**：
- 用户名
- 密码

**输出**：
- 登录成功：进入系统仪表盘
- 登录失败：显示错误提示信息

**业务规则**：
- 用户名和密码必须匹配
- 密码使用安全哈希存储
- 支持记住登录状态

#### 2.1.2 用户登出

**需求描述**：系统应支持用户登出功能

**输入**：
- 登出请求

**输出**：
- 退出当前用户会话
- 重定向到登录页面

**业务规则**：
- 登出后清除用户会话信息
- 清除记住的登录状态

### 2.2 数据导入功能

#### 2.2.1 Excel文件导入

**需求描述**：系统应支持从Excel文件导入各类业务数据

**输入**：
- Excel文件
- 导入类型（Onboarding配置、融资订单、还款订单、银行对账单、融资概览、批次号）
- 银行渠道（默认DB）

**输出**：
- 导入成功：显示导入结果（新增记录数、更新记录数）
- 导入失败：显示错误提示信息

**业务规则**：
- 支持.xlsx和.xls格式的Excel文件
- 导入数据前进行格式验证和清洗
- 支持幂等导入（已存在的记录更新，不存在的记录插入）
- 导入后自动触发数据聚合

#### 2.2.2 API导入

**需求描述**：系统应支持从API导入业务数据

**输入**：
- 导入类型（还款订单、融资订单）

**输出**：
- 导入成功：显示导入结果（新增记录数、更新记录数）
- 导入失败：显示错误提示信息

**业务规则**：
- 从指定的API端点获取数据
- 支持幂等导入
- 导入后自动触发数据聚合

### 2.3 数据导出功能

#### 2.3.1 标准数据导出

**需求描述**：系统应支持将各类业务数据导出为Excel、CSV、PDF格式

**输入**：
- 数据类型（融资订单、还款订单、银行对账单、融资概览）
- 导出格式（Excel、CSV、PDF）
- 过滤条件（可选：融资申请号、发票号）

**输出**：
- 导出文件

**业务规则**：
- 根据用户选择的格式生成对应文件
- 支持自定义过滤条件
- 导出文件包含所有相关字段
- 导出后浏览器自动下载文件

#### 2.3.2 DB放款文件生成

**需求描述**：系统应支持生成DB放款文件

**输入**：
- 批次日期
- 银行渠道（默认DB）

**输出**：
- 包含所有符合条件融资单的Excel文件压缩包

**业务规则**：
- 自动生成批次号
- 将符合条件的融资单分组生成Excel文件
- 每个供应商生成一个独立的Excel文件
- 生成汇总Excel文件
- 所有文件打包为ZIP格式

#### 2.3.3 DB还款文件生成

**需求描述**：系统应支持生成DB还款文件

**输入**：
- 还款日期
- 银行渠道（默认DB）

**输出**：
- 包含所有符合条件还款记录的Excel文件压缩包

**业务规则**：
- 筛选WIP/Pending>0且DB loan settle date为空的数据
- 生成还款文件后更新融资单的还款日期
- 按供应商分组生成Excel文件
- 生成汇总Excel文件
- 所有文件打包为ZIP格式

### 2.4 数据聚合功能

#### 2.4.1 全量数据聚合

**需求描述**：系统应支持将融资订单、还款记录和银行对账单数据聚合到融资概览表

**输入**：
- 聚合请求

**输出**：
- 聚合成功：显示聚合结果（更新记录数）
- 聚合失败：显示错误提示信息

**业务规则**：
- 筛选银行对账单中状态为"Financing confirmed"的数据
- 按发票号关联融资订单
- 按融资申请号关联还款记录
- 支持并行处理提高效率
- 批量更新或插入融资概览记录

#### 2.4.2 部分数据聚合

**需求描述**：系统应支持按融资申请号进行部分数据聚合

**输入**：
- 融资申请号

**输出**：
- 聚合成功：显示聚合结果
- 聚合失败：显示错误提示信息

**业务规则**：
- 仅聚合指定融资申请号的数据
- 更新对应融资概览记录

### 2.5 批次管理功能

#### 2.5.1 批次查询

**需求描述**：系统应支持查询批次信息

**输入**：
- 查询请求

**输出**：
- 批次列表（批次号、批次状态、生成时间、记录数）

**业务规则**：
- 显示所有批次信息
- 支持分页和排序

#### 2.5.2 批次作废

**需求描述**：系统应支持作废批次

**输入**：
- 批次号
- 作废确认

**输出**：
- 作废成功：显示成功提示
- 作废失败：显示错误提示信息

**业务规则**：
- 清除该批次下所有融资单的批次信息
- 触发数据聚合刷新概览表
- 记录批次作废操作日志

#### 2.5.3 还款批次管理

**需求描述**：系统应支持管理还款批次

**输入**：
- 查询请求
- 还款日期

**输出**：
- 还款批次列表
- 作废结果

**业务规则**：
- 显示所有还款批次信息
- 支持作废还款批次
- 作废后删除批次记录并清空融资单的还款日期

### 2.6 仪表盘功能

#### 2.6.1 数据统计

**需求描述**：系统应在仪表盘显示各类数据的统计信息

**业务规则**：
- 按到期日排序
- 支持过滤零欠款记录
- 支持导出报表

#### 2.6.3 DB放款报表

**需求描述**：系统应在仪表盘显示DB放款报表

**输出**：

**业务规则**：
- 按批次号排序

- 支持导出报表

#### 2.6.4 融资单统计图表

**输出**：

- 月度有对账单的融资单数量统计
- 逾期融资单统计

**业务规则**：
- 支持按供应商过滤
- 图表可交互
- 支持导出图表

## 3. 非功能需求

### 3.1 性能需求

1. **响应时间**
   - 登录/登出操作：≤2秒
   - 数据查询：≤3秒
   - 数据导入：≤30秒（1000条记录）
   - 数据导出：≤60秒（1000条记录）
   - 数据聚合：≤120秒（10000条记录）

2. **并发处理**
   - 支持100个并发用户
   - 支持10个并发数据导入操作
   - 支持20个并发数据查询操作

3. **吞吐量**
   - 数据导入：≥100条记录/秒
   - 数据导出：≥50条记录/秒
   - 数据聚合：≥200条记录/秒

### 3.2 安全需求

1. **数据安全**
   - 敏感数据加密存储
   - 支持数据备份和恢复
   - 实现数据访问控制

2. **系统安全**
   - 防止SQL注入攻击
   - 防止跨站脚本攻击（XSS）
   - 防止跨站请求伪造（CSRF）
   - 实现请求频率限制

3. **网络安全**
   - 支持HTTPS协议
   - 实现API访问控制
   - 记录安全事件日志

### 3.3 可用性需求

1. **系统可用性**
   - 系统可用性：≥99.5%
   - 计划维护时间：每月4小时（非业务时间）
   - 故障恢复时间：≤2小时

2. **数据可用性**
   - 数据备份频率：每日
   - 备份保留时间：30天
   - 支持数据恢复

### 3.4 可扩展性需求

1. **功能扩展**
   - 支持新增银行渠道
   - 支持新增数据导入导出格式
   - 支持新增报表类型

2. **性能扩展**
   - 支持数据库分片
   - 支持负载均衡
   - 支持水平扩展

### 3.5 可维护性需求

1. **代码质量**
   - 代码符合PEP8规范
   - 代码测试覆盖率：≥80%
   - 文档完整度：≥90%

2. **系统监控**
   - 实现系统性能监控
   - 实现错误日志监控
   - 实现安全事件监控

## 4. 业务流程

### 4.1 数据导入流程

1. 用户选择导入类型
2. 用户选择Excel文件
3. 用户选择银行渠道（可选）
4. 系统验证文件格式
5. 系统清洗和验证数据
6. 系统导入数据到数据库（upsert）
7. 系统触发数据聚合
8. 系统显示导入结果

### 4.2 数据导出流程

1. 用户选择数据类型
2. 用户选择导出格式
3. 用户设置过滤条件（可选）
4. 系统查询符合条件的数据
5. 系统转换数据为指定格式
6. 系统生成导出文件
7. 系统将文件发送给用户

### 4.3 数据聚合流程

1. 系统筛选银行对账单中状态为"Financing confirmed"的数据
2. 系统按发票号关联融资订单
3. 系统按融资申请号关联还款记录
4. 系统并行处理银行对账单
5. 系统构建融资概览记录
6. 系统批量更新或插入融资概览记录
7. 系统显示聚合结果

### 4.4 批次管理流程

1. 系统生成下一个批次号
2. 系统筛选符合条件的融资订单
3. 系统更新融资订单的批次相关字段
4. 系统生成DB放款文件
5. 用户可查询和作废批次
6. 作废批次时清除融资单的批次信息
7. 系统触发数据聚合刷新概览表

## 5. 数据规范

### 5.1 数据字段规范

#### 5.1.1 日期字段

- 格式：ISO 8601（YYYY-MM-DD）
- 存储：Date类型
- 显示：根据用户语言偏好格式化

#### 5.1.2 数值字段

- 类型：Decimal128（高精度小数）
- 精度：2位小数
- 货币：支持多货币（USD、CNY等）

#### 5.1.3 字符串字段

- 长度：根据实际需求设置
- 编码：UTF-8
- 空值处理：使用空字符串而非NULL
